# Правила работы

- Общайся с пользователем по-русски, коротко и понятно.
- Требования продукта находятся в PROJECT.md. Читай его при начале работы над магазином.
- Используй готовый открытый код, если он подходит. Перед выбором проверь лицензию, реальную реализацию и запуск; README не доказывает работоспособность.
- Не подключай платные сервисы и подписки без прямого согласия пользователя.
- Ищи нужные файлы точечно через rg. Не читай весь репозиторий, зависимости, сборки и журналы без необходимости.
- Не создавай дополнительные планы и отчёты ради документации. После этапа коротко обновляй раздел «Состояние» в PROJECT.md.
- Не используй субагентов без просьбы пользователя.
- Делай небольшие изменения и запускай относящиеся к ним проверки. Не повторяй успешные проверки без новых изменений или причин.
- Перед коммитом проверяй diff и отсутствие секретов. Не добавляй токены, .env, базы заказов и персональные данные в Git.
- Сохраняй лицензии и авторство используемого открытого кода.
- Не делай force push, не переписывай историю и не удаляй пользовательские изменения без прямого указания.
- По завершении сообщай: что сделано, как проверено, что осталось. Не называй непроверенные функции готовыми.
